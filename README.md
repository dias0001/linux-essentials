# 🐧 Linux Estudos | Linux Essentials → LPIC-1

Repositório pessoal dedicado ao aprendizado prático de Linux, com foco nos fundamentos do sistema operacional, administração de sistemas e preparação para as certificações **Linux Essentials** e **LPIC-1**.

## 🎯 Objetivo

Construir uma base sólida em Linux, combinando teoria, prática no terminal, resolução de problemas e documentação dos laboratórios.

Os conhecimentos também contribuem para minha formação em redes e segurança defensiva (**Blue Team**).

## 💻 Ambiente de laboratório

- **Sistema operacional:** Ubuntu em máquina virtual
- **Acesso remoto:** SSH
- **Editor:** Visual Studio Code com Remote SSH
- **Shell:** Bash
- **Versionamento:** Git e GitHub

## 🔍 Conhecimentos praticados

- Navegação no sistema de arquivos Linux.
- Diferença entre arquivos e diretórios.
- Caminhos absolutos e relativos.
- Criação e consulta de contas de usuários.
- Estrutura do arquivo `/etc/passwd`.
- Processamento de texto com `grep` e `cut`.
- Encadeamento de comandos com pipe (`|`).
- Interpretação de mensagens de erro.
- Documentação e versionamento com Git.
