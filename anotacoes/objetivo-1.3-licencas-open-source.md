# Objetivo 1.3 — Software Open Source e Licenciamento

## Gratuito não significa Open Source

Um programa pode ser gratuito e ainda assim ter seu código-fonte fechado.

Software Open Source permite acessar, estudar, modificar e redistribuir o código, respeitando as condições de sua licença.

## O que é uma licença?

A licença estabelece as condições de uso, modificação e distribuição de um software.

## GPL e Copyleft

A GPL utiliza o princípio do *copyleft*, que busca preservar as liberdades do software quando ele é redistribuído.

- Modificar um programa GPL apenas para uso interno não obriga, por si só, a publicar as alterações.
- Ao distribuir uma versão modificada, é necessário cumprir as condições da GPL, incluindo as obrigações relativas ao código-fonte correspondente.
- Software GPL pode ser vendido.

## Licença MIT

A MIT é uma licença permissiva.

Ela permite modificar e distribuir software, inclusive incorporá-lo em produtos proprietários, desde que suas condições sejam respeitadas, como preservar os avisos de direitos autorais e da licença.

## Diferença principal

- **GPL:** utiliza copyleft e estabelece condições para preservar as liberdades na redistribuição.
- **MIT:** permite maior flexibilidade na distribuição de versões derivadas.

## Exemplo real

O kernel Linux utiliza a licença GPLv2.

## O que aprendi

- Software gratuito e Open Source não são a mesma coisa.
- Disponibilidade do código-fonte não elimina as obrigações da licença.
- Uso interno e distribuição são situações diferentes.
- GPL e MIT são licenças Open Source com condições diferentes.

## As quatro liberdades do Software Livre — FSF

A Free Software Foundation (FSF), fundada por Richard Stallman, estabelece quatro liberdades essenciais:

| Liberdade                            | Descrição 
|--------------------------------------|----------------------------------------------------
| 0 — Executar                         | Executar o programa para qualquer finalidade. |
| 1 — Estudar e modificar              | Estudar o funcionamento do programa e modificá-lo. |
| 2 — Redistribuir                     | Compartilhar cópias do programa. |
| 3 — Distribuir modificações          | Compartilhar versões modificadas do programa. |

As liberdades 1 e 3 dependem do acesso ao código-fonte.

**Memorização:** 0 = Executar; 1 = Estudar e modificar; 2 = Redistribuir; 3 = Distribuir modificações.

## FSF e OSI

- **FSF — Free Software Foundation:** enfatiza as liberdades dos usuários e os princípios éticos do Software Livre.
- **OSI — Open Source Initiative:** enfatiza o modelo de desenvolvimento aberto e colaborativo.

As duas organizações possuem abordagens diferentes, mas compartilham muitos princípios relacionados ao software livre e de código aberto.

## FOSS e FLOSS

**FOSS:** Free and Open Source Software.

**FLOSS:** Free/Libre and Open Source Software.

A palavra **Libre** reforça que estamos falando de liberdade, não necessariamente de gratuidade.

## Licenças permissivas e Copyleft

------------------------------------------------------------------------------------------------------------------------------------------------
| Licença            Classificação |    Característica |                                                                                       -
|------------------------------------------------------------------------------------------------------------------------------------------------
| GPLv3              Copyleft   |       Preserva as liberdades nas versões derivadas distribuídas. |                                           -
| BSD Simplificada   Permissiva |       Permite distribuir versões proprietárias, respeitando suas condições. |
| MIT                Permissiva |       Permite reutilização comercial e proprietária, mantendo os avisos exigidos. |
| CC BY              Permissiva |       Permite adaptações, exigindo atribuição ao autor. |
| CC BY-SA           Copyleft   |       Exige atribuição e compartilhamento das adaptações sob a licença correspondente. |
------------------------------------------------------------------------------------------------------------------------------------------------

A GPL e a BSD são utilizadas em software. As licenças Creative Commons são voltadas principalmente para obras criativas e materiais de conteúdo.

## Creative Commons

As condições fundamentais são:

- **BY — Atribuição:** dar os créditos ao autor.
- **SA — CompartilhaIgual:** compartilhar adaptações sob a licença exigida.
- **NC — NãoComercial:** restringir o uso comercial.
- **ND — SemDerivações:** não compartilhar versões modificadas.

### As seis licenças Creative Commons

| Licença           Característica |
|------------------------------------------------------------------------------------------------------------------------------------------------
| CC BY |           Permite adaptações e uso comercial, exigindo atribuição. |
| CC BY-SA |        Permite adaptações e uso comercial, mantendo a licença exigida. |
| CC BY-ND |        Permite compartilhar a obra sem distribuir modificações. |
| CC BY-NC |        Permite adaptações para fins não comerciais. |
| CC BY-NC-SA |     Permite adaptações não comerciais, mantendo a licença exigida. |
| CC BY-NC-ND |     Permite compartilhar a obra inalterada e somente para fins não comerciais. |
------------------------------------------------------------------------------------------------------------------------------------------------

Todas exigem atribuição ao autor.

## Modelos de negócios Open Source

O Software Livre pode gerar receita por diferentes modelos:

1. **Suporte técnico:** instalação, manutenção e resolução de problemas.
2. **Consultoria:** planejamento e implantação de soluções.
3. **Desenvolvimento personalizado:** adaptações para clientes.
4. **SaaS — Software as a Service:** fornecimento de software como serviço.
5. **Dual Licensing:** disponibilização do software sob duas opções de licenciamento.
6. **Crowdfunding:** financiamento coletivo do desenvolvimento.

Software Livre não significa que os serviços profissionais precisem ser gratuitos.
